# Future Professional Profiles

Researched professional positioning, content strategy and an alternate-future publishing
system. An RN Studio concept line.

**Live:** https://future-professional-profiles.vercel.app

## What this establishes

That a profile can be built from researched material rather than self-description: each
one sets out a position, the evidence behind it, and a publishing approach that follows
from both.

## What it does not establish

These are concept profiles. They are not commissioned work, not endorsements, and not
claims about the people or roles they describe. Nothing here has been agreed with a
subject, and no profile should be read as representing anyone's actual plans.

## Repository

Next.js and TypeScript. `research/` holds the source material each profile is built from;
`deployments/` holds the published versions.
